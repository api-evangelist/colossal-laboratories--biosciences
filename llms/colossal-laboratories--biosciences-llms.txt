Colossal Laboratories & Biosciences is a Dallas, Texas genetic-engineering and de-extinction
company founded in 2021 by Ben Lamm and Dr. George Church. It applies ancient-DNA sequencing,
comparative genomics, multiplex CRISPR editing and cellular engineering to functional
de-extinction and endangered-species conservation — active programs on the woolly mammoth,
thylacine, dodo, dire wolf, moa and bluebuck, plus the Colossal Biovault biobanking program.

Colossal publishes **no product API, no developer portal, no documentation and no OpenAPI**. The
only machine-readable surface on colossal.com is the WordPress REST API its CMS exposes, plus a
WordPress MCP Adapter endpoint that is authentication-gated.

## APIs

- [Colossal Content API (WordPress REST wp/v2)](https://colossal.com/wp-json/wp/v2): Anonymously
  readable CMS content API — 238 posts, 59 pages, 990 media items, 15 categories, 156 tags, 8
  contributor accounts and a site-wide search over 297 indexed objects. Page-number pagination
  with X-WP-Total / X-WP-TotalPages. Writes require a WordPress Application Password.
- [Colossal MCP Server (WordPress MCP Adapter)](https://colossal.com/wp-json/mcp): Live MCP
  endpoint at /wp-json/mcp/mcp-adapter-default-server. Anonymous tools/list and initialize both
  return HTTP 401 rest_forbidden, so the tool set is not publicly observable.

## Content types NOT readable as JSON

Colossal publishes five custom post types that appear in the sitemap index but are **not**
registered with the REST API, so no agent can read them as structured data:

- [Papers](https://colossal.com/paper-sitemap.xml) — the company's scientific publications
- [Podcast](https://colossal.com/podcast-sitemap.xml)
- [Team](https://colossal.com/team-sitemap.xml)
- [FAQ](https://colossal.com/faq-sitemap.xml)
- [PDFs](https://colossal.com/pdf-sitemap.xml)

This is the single largest machine-readability gap on the property, and closing it takes a
`show_in_rest` flag, not an engineering project.
